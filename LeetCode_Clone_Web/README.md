## 🚀 **Getting Started**

### **Installation**
```bash
# Clone the repository
git clone <repository-url>
cd LeetCode_Clone_Web

# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
```

### **Access the Application**
Open your browser and go to:
```
http://127.0.0.1:5000
```
